# BarberShop PWA

Una Progressive Web Application (PWA) para una barbería, construida con **Astro**.

## Características

- ✅ Diseño mobile-first
- ✅ Interfaz profesional con UX/UI de calidad
- ✅ Modo standalone (agregable a pantalla principal)
- ✅ Manifiesto PWA configurado
- ✅ Acceso offline básico
- ✅ Tema oscuro premium

## Tecnologías

- **Astro** 7.3.5 - Framework de estaticos modernos
- **Tailwind CSS** - Estyling utility-first
- **Atkinson** - Fuente personalizada
- **Service Worker** - Capacidades PWA

## Páginas

- `/` - Página principal
- `/login` - Pantalla de inicio de sesión
- `/blog` - Sección de blog

## Build

```bash
npm run dev    # Servidor de desarrollo
npm run build  # Compilar para producción
npm run preview # Preview de producción
```
